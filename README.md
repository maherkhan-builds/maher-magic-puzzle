## 🔗 Live Game

**▶️ https://maherkhan-builds.github.io/maher-magic-puzzle/** — works on phones, tablets, and desktops.

## 🎯 The Problem

Sliding puzzles are timeless, but every app version locks you into stock artwork, ads, or app-store downloads. Parents want a safe game with *their kids' own photos*; brands want an interactive product experience they can drop into a campaign page — without commissioning a custom game build.

## 💡 The Solution

One tap: upload any image — a family photo, a product shot, a Pinterest find — and it instantly becomes a playable sliding puzzle:

- 🖼️ **Your image, your puzzle** — drag & drop or pick from your phone gallery; saved privately in your browser
- 🎚️ **Three levels** — Beginner 3×3, Advanced 4×4, Expert 5×5, with a best-score tracker per level
- 🧩 **Always solvable** — shuffled with real moves, so every game has a solution
- 🔊 **Satisfying slide "snap"** on every tile — synthesized live with the Web Audio API
- 🎉 **Win celebration** — confetti, victory fanfare, and applause
- 👀 **Hold to peek** at the full picture; 🔢 optional tile numbers for young kids

## 👥 Who It's For

- **Families & kids** — turn vacation photos into games (numbers mode makes it toddler-friendly)
- **Brands & marketers** — an instant interactive product experience for campaign microsites
- **Teachers** — a focus-and-reward activity with any lesson image

## 🚀 How to Use

1. **Play instantly** → https://maherkhan-builds.github.io/maher-magic-puzzle/
2. Tap **Change image** and pick any photo
3. Choose your level and slide tiles into place — hold to peek when stuck

**Embed on any website** — the whole game is one `index.html`:

```html
<iframe src="https://maherkhan-builds.github.io/maher-magic-puzzle/"
        width="420" height="900" style="border:0;border-radius:20px"></iframe>
```

## 🛠️ Tech Stack

Plain HTML + CSS + JavaScript in **one single file** — no frameworks, no build step, no assets. The default artwork, all sounds, and the confetti are generated entirely in code.
